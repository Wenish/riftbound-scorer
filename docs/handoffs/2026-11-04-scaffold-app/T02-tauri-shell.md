## Brief

### Goal

A Tauri 2 project in `src-tauri/` that wraps the Vite frontend from T01, compiles (`cargo check`), and is
wired into `package.json` so `pnpm tauri dev` / `pnpm tauri build` would use the Vite dev server / `dist`.

### Scope

- Files to create/change: `vite.config.ts`, `src-tauri/**` (`Cargo.toml`, `build.rs`, `tauri.conf.json`,
  `src/main.rs`, `src/lib.rs`, `capabilities/default.json`, `icons/*`, `.gitignore` inside `src-tauri`
  if the template provides one), `package.json` (deps + `tauri` script), `pnpm-lock.yaml`.
- Add devDependency `@tauri-apps/cli` (v2) and dependency `@tauri-apps/api` (v2). Script: `"tauri": "tauri"`.
- Generate the skeleton with the Tauri CLI non-interactively, e.g.
  `pnpm tauri init --ci --app-name riftbound-scorer --window-title "Riftbound Scorer" --frontend-dist ../dist --dev-url http://localhost:1420 --before-dev-command "pnpm dev" --before-build-command "pnpm build"`
  (check `pnpm tauri init --help` for exact flags), then adjust by hand. Do **not** run `tauri ios init` / `tauri android init`.
- `tauri.conf.json`: `productName` "Riftbound Scorer", `identifier` `app.riftboundscorer`
  (no `com.tauri.dev`), version `0.1.0`, `devUrl` `http://localhost:1420`, `frontendDist` `../dist`,
  one window titled "Riftbound Scorer" (portrait-ish dev size, e.g. 420×860), a restrictive CSP
  (`default-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:` — adjust minimally if
  Tauri needs `ipc:`/`asset:` sources, and say so in the handoff).
- Rust: `lib.rs` exposes `run()` with `#[cfg_attr(mobile, tauri::mobile_entry_point)]` (mobile-ready
  layout); `main.rs` calls it with `windows_subsystem` attribute. `Cargo.toml` `[lib]` with
  `crate-type = ["staticlib", "cdylib", "rlib"]` and a lib name like `riftbound_scorer_lib`.
  No plugins yet (no `tauri-plugin-opener` / `-sql`) — remove any the template adds, including from capabilities.
- Capabilities: only `core:default` for the `main` window.
- Icons: keep the default Tauri icons generated by init (or `pnpm tauri icon` from a placeholder); a real icon is a follow-up.
- Update the root `.gitignore` only if something generated by Tauri is not yet ignored
  (T01 already added `src-tauri/target` and `src-tauri/gen/schemas`).

- `vite.config.ts` (allowed in this task): add the usual Tauri dev settings — `server.host` from
  `process.env.TAURI_DEV_HOST` (with matching `hmr` config when set, needed for mobile dev),
  `server.watch.ignored: ['**/src-tauri/**']`, and `envPrefix: ['VITE_', 'TAURI_ENV_*']`. Keep the existing
  port 1420 / `strictPort` / `clearScreen: false` / `test` block. `process.env` already type-checks
  (`tsconfig.node.json` has `types: ["node"]`).

### Out of scope

- iOS/Android project generation, signing, mobile builds.
- Tauri plugins (SQL, keep-awake), platform adapters, any frontend change beyond `package.json`.
- PWA. Don't edit `docs/` (except this task file's Handoff), `CLAUDE.md`, `.claude/`.
- A full `pnpm tauri build` bundle is not required (slow); `cargo check` is enough.

  Removing them is fine if a reviewer wants the crate minimal.

  devUrl `http://localhost:1420`, frontendDist `../dist`, before-dev `pnpm dev`, before-build `pnpm build`.
  There is one window with the explicit label `main`, title "Riftbound Scorer", size 420×860.
  I kept the template's `bundle` block (default icons, `targets: "all"`, Android `debugApplicationIdSuffix: ".debug"`).
- **CSP deviation (minimal addition):**
  `default-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src ipc: http://ipc.localhost`.
  I added `connect-src ipc: http://ipc.localhost` because Tauri does not inject IPC sources into the CSP itself.
  I checked the Tauri sources: the only mention is the documented example in `tauri-utils` `config.rs`, which
  uses exactly this `connect-src`. Without it, `default-src 'self'` blocks the IPC custom protocol. Tauri then
  falls back to postMessage and logs a warning. `ipc:` and `http://ipc.localhost` are local custom-protocol
  handlers inside the webview (Windows and Android use the `http://ipc.localhost` form). They are not network
  access. I added no `asset:` source because nothing uses the asset protocol.
- Capabilities: `core:default` for the `main` window, nothing else.
- Icons: the default Tauri icons from `init`.
- `vite.config.ts` changes:
  - `envPrefix: ['VITE_', 'TAURI_ENV_*']`
  - `server.host` set to `TAURI_DEV_HOST || false`
  - `server.hmr` set to `{ protocol: 'ws', host, port: 1421 }` when that host is set, otherwise `undefined`
  - `server.watch.ignored: ['**/src-tauri/**']`

  Port 1420, `strictPort`, `clearScreen: false` and the `test` block are unchanged.
- `init` also created `src-tauri/.gitignore` (`/target/`, `/gen/schemas`), and I kept it. The root `.gitignore`
  needed no change. `src-tauri/Cargo.lock` is not ignored and should be committed, since this is an app crate.
